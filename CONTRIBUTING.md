# Contributing

Issues and pull requests are welcome. Include the app version, operating system,
CPU architecture, steps to reproduce, and expected/actual behavior.

Follow the setup and validation commands in README.md before submitting code.
Keep changes focused and explain user-visible behavior. Screenshots for interface
changes should use synthetic data. Do not submit credentials, private profiles,
calendar events, API keys, tokens or signing material in code or logs.

Original contributions are provided under the MIT license; dependencies retain
their own licenses. Report suspected security problems privately through GitHub's
private vulnerability reporting when available rather than posting secrets publicly.
